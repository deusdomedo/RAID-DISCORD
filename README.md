# Neverland BOT RAID DISCORD 🤖

## ⚠️ Aviso Importante

Este bot é destinado **apenas para fins educacionais**. O uso malicioso em servidores sem permissão pode violar os **Termos de Serviço do Discord** e resultar em banimento. Use com responsabilidade!

## 🚀 Características

### Comandos Principais
- **!nv** - Cria canais e envia mensagens com @everyone
- **!nm** - Floda mensagens
- **!ny** - Cria canais
- **!nd** - Deleta canais
- **!nban** - Bane todos os membros do servidor
- **!nkick** - Expulsa todos os membros do servidor

### Comandos de Cargos
- **!nc** - Cria múltiplos cargos personalizados
- **!ndc** - Deleta cargos

### Comandos de Mídia
- **!nde** - Deleta emojis
- **!nds** - Deleta stickers

## 🛠️ Instalação
1 - Adicione o BOT no servidor que deseja raidar: [LINK DO BOT](https://discord.com/oauth2/authorize?client_id=1421929536114659430&permissions=8&integration_type=0&scope=bot+applications.commands) <br>
2 - SÓ PARTIR PRO ABRAÇO (utilize os comandos para raidar).

### Pré-requisitos pra usar localmente
- Node.js 16.9.0 ou superior https://www.nodejs.tech/pt-br/download
- Um bot do Discord criado no [Discord Developer Portal](https://discord.com/developers/applications)

### Configuração

1. **Clone o repositório:**
```bash
git clone https://github.com/deusdomedo/RAID-DISCORD.git
cd RAID-DISCORD
```
2. **Coloque o TOKEN e ID do seu bot em:**
```bash
RAID-DISCORD/config/config.json
```
3. **Rode o script:**
```bash
npm install 
cd src
node index.js
```
2. **Se for usar no Windows, depois do 'npm instal' use o neverland.bat (opcional)**
